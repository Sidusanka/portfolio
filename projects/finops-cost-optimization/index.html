Cloud efficiency

FinOps cost optimization

Moved legacy Azure VM SKUs to more efficient options and decommissioned unused resources to reduce cloud spend.

My role
VM SKU migration and resource cleanup
Technologies
Azure · FinOps

Context

Azure cost optimization was part of my cloud platform work.

Problem

Some virtual machines used legacy SKUs and some Azure resources were no longer in use.

My contribution

I moved legacy VM SKUs to more efficient alternatives and decommissioned unused resources.

Approach

The work followed two paths. Virtual machines that still served a purpose were moved to a more efficient SKU. Unused resources were retired.

Outcome

The migrations and decommissioning contributed to cloud cost savings.

Engineering takeaway

A cloud cost review should distinguish resources that need a more efficient configuration from those that can be retired entirely.
